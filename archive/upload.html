壹GitHub 令牌

用来把加密后的戏录直接提交到网站仓库。只需要设置一次；令牌只存在这台设备的浏览器里。没有令牌也可以用最下面的「下载存档包」。

怎么获取令牌？
  1. 登录 GitHub，打开 Settings → Developer settings → Personal access tokens → Fine-grained tokens，点 Generate new token。
  2. Repository access 选 Only select repositories，只勾 ChiliKwok/ChiliKwok.github.io。
  3. Permissions 里把 Contents 设为 Read and write，其余不用动。
  4. 生成后复制，粘贴到上面。令牌就像钥匙，不要发给别人。
